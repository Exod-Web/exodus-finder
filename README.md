# Exodus Erlebnis-Finder

Erlebnis-Finder für exodus-hn.de (Webflow). Wird über jsDelivr eingebunden:

    https://cdn.jsdelivr.net/gh/Exod-Web/exodus-finder@1.1.0/exodus-finder.min.js

- `exodus-finder.min.js` – die Datei, die Webflow lädt
- `exodus-finder.js` – lesbarer Quelltext

Neue Version: beide Dateien ersetzen, dann ein neues Release mit neuer Versionsnummer anlegen
und die Nummer im Webflow-Schnipsel anpassen.
